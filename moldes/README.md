# Moldes

O contrato de adaptação: o que cada projeto precisa informar para que o núcleo vire o sistema agêntico dele.

Moldes previstos:
- **Perfil do projeto:** contexto, objetivos, papéis e quem os ocupa, stack, padrões do cliente, normas do domínio, restrições de uso de IA, onde ficam os artefatos.
- **Agente de domínio:** estrutura para criar agentes que só fazem sentido num projeto (por exemplo, análise de sistema legado ou de normas de um setor).
- **Ajuste de método:** como uma instância muda responsáveis por portão, etapas ou acordos (DoR/DoD) sem alterar o núcleo.

Um molde preenchido é dado do projeto e **não volta para este repositório**. Aqui ficam só os moldes vazios e o preenchimento fictício do exemplo.
