# Definition of Done (DoD)

<!-- Acordo da equipe. Checado no Portão 2 (DV6). -->

Uma feature está pronta (código) quando:

- [ ] Todos os cenários Gherkin automatizados e passando.
- [ ] Testes de unidade para cada RN, passando.
- [ ] Nenhum teste pulado, desativado ou removido sem registro.
- [ ] Implementação conforme `dv3-contratos.md`.
- [ ] Revisado por outro dev, sem achado bloqueante aberto.
- [ ] Sem segredos no código; entradas validadas.
- [ ] Logs e métricas mínimos da feature presentes.
- [ ] Documentação de uso ou API atualizada.
- [ ] Integrado à branch principal sem quebrar o build.
