# Forjar

O processo que transforma núcleo + perfil do projeto num sistema agêntico do projeto.

Passos (a detalhar):
1. Preencher o perfil do projeto a partir do molde.
2. Selecionar os componentes do núcleo que o projeto usa.
3. Aplicar o perfil nos pontos de extensão.
4. Criar os agentes de domínio a partir do molde.
5. Gerar a instância no local do projeto, registrando a versão do núcleo usada.

A forma de execução (skill interativa ou roteiro manual) está em aberto na [ADR 0001](../docs/decisoes/0001-forja-de-sistemas-agenticos.md).
