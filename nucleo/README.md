# Núcleo

O que é coringa: entra em todo sistema agêntico forjado. Nada aqui cita projeto, cliente ou pessoa real.

```
metodo/      O processo SDD: fases, etapas, portões, DoR/DoD (HEFESTO.md)
agentes/     Agentes base, um por papel no método
skills/      Skills base usadas pelos agentes
templates/   Templates de artefatos, com exemplo do Portal de Cursos
```

Cada componente declara seus **pontos de extensão**: o que lê do perfil do projeto (ver `moldes/`) e o que uma instância pode substituir. Um componente sem pontos de extensão é usado como está.

Critério para entrar aqui: ver [docs/visao.md](../docs/visao.md#critério-para-algo-entrar-no-núcleo).
